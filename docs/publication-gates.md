# Publication Gates

Publication readiness is generated for every editorial entity. Checks cover content, editorial state, verification, sources, rights, evidence, claims, conflicts, relationships, accessibility and SEO categories.

A record is publishable only when no check is blocked. Unknown, all-rights-reserved and permission-required source rights block reproduction and publication where the record depends on reuse. A link-only catalog record may remain editorially useful without hosting protected content.

The final public compiler filters both by explicit `status: published` and readiness. Draft records may appear in internal review output but never in public entities, search or sitemap data.
