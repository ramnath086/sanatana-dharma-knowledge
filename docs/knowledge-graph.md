# Knowledge Graph

The graph is built from sourced Markdown relationship records. It includes text-to-text, text-to-person, school-to-ācārya, concept-to-concept and entity-to-domain relationships.

Relationships are directed and are not automatically reciprocated. For example, Bhagavad Gītā `part-of` Mahābhārata does not silently generate a reciprocal `contains` relationship. Each relationship may carry sources and an editorial note.
