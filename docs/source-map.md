# Source Map

The initial source map is intentionally small. Seed sources cover Vedic heritage, Sanskrit texts, digital libraries, manuscripts, Āgama/Tantra materials and institutional collections.

Each source record declares its scope, language, authority context, rights state and intended use. Unknown rights remain non-reusable and source records are linked rather than copied. The first published records use the GRETIL source as a link-only catalogue/reference source; no third-party text is reproduced.
