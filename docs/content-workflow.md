# Content Workflow

Every record moves through this path:

`DISCOVER → RESEARCH → SOURCE CHECK → STRUCTURE → DRAFT → VERIFY → EDITORIAL REVIEW → PUBLISH`

Use `status` to represent workflow state and `verification` to represent provenance review. Verification does not mean universal agreement. A record may have a traditional review, scholarly review, or both, and differing accounts should remain distinguishable.

Run `npm run validate-content` before submitting a change. It checks IDs, frontmatter, controlled vocabularies, source references, relationships and library copyright rules.
