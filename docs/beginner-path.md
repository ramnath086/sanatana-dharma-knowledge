# Beginner Path

The homepage beginner path is resolved from compiled entity IDs rather than duplicated card prose. It currently guides users through Dharma, Rigveda, Upaniṣadic category, Bhagavad Gītā, Karma, Mokṣa, Nyāya and Pūjā.

As the seed grows, the path can add relationships to Itihāsa, Darśana, practices and sources without creating a second content model. Draft entities remain unavailable to public discovery until publication gates pass.
