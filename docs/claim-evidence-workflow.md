# Claim and Evidence Workflow

Claims are added only when they provide useful factual structure. Evidence should point to a source and locator or bibliographic context without copying protected text.

Claims distinguish textual, historical, traditional, linguistic, ritual, philosophical, geographical, biographical and bibliographical types. Evidence distinguishes primary-text, secondary-source, traditional-account, scholarly-interpretation, modern-interpretation and regional-tradition perspectives.

Unresolved or weakly supported claims remain draft/review and do not become public merely because an entity is otherwise complete.
