# Persistence Boundary

Phase 10 remains static and low-cost.

Static canonical/public material:

- Markdown entities, sources, claims and evidence
- Generated public entities and relationships
- Search index
- Taxonomy and category pages
- Sitemap

A future persistent editorial system may store:

- User and role
- Editorial session
- Review
- Approval
- Publication batch
- Source verification
- Claim review
- Evidence review
- Activity log

No database, backend, authentication or persistent editorial accounts are implemented in this phase. Markdown remains canonical until a future phase defines a protected synchronization boundary.
