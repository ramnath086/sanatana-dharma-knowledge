# Sources

Source transparency is a core feature of this project. Content records should link to the edition, archive, institution or community source that informed them.

The initial source records are intentionally marked as sample data. They demonstrate the catalogue shape and must be verified before publication. Useful starting points include institutional catalogues, public digital text collections, scholarly reference works and sources provided by living traditions.

For each source, record:

- title and publisher
- stable URL or bibliographic reference
- access date where useful
- the claim or page it supports
- any license or usage conditions

The portal does not reproduce copyrighted translations or editions. It links outward and adds original, clearly scoped summaries.
